# Normalization and Constraints – Monica Irala

## My Role

My role in the UniTrack DBMS project is **Normalization and Constraints**.

## Work Done

I am responsible for:

- Identifying functional dependencies in the database.
- Analyzing the database structure using **1NF, 2NF, and 3NF**.
- Checking and reducing data redundancy through normalization.
- Identifying the **primary keys and foreign keys** relevant to the normalized design.
- Defining integrity constraints such as:
  - NOT NULL
  - UNIQUE
  - CHECK
  - DEFAULT
  - FOREIGN KEY
  - ON DELETE
  - ON UPDATE
- Providing the constraint requirements for the SQL table implementation.

## Deliverables

- Functional dependency analysis
- 1NF, 2NF, and 3NF analysis
- Final normalized schema
- Integrity constraint specification
- Constraint justification

## Contribution to the Project

My work ensures that the UniTrack database is properly normalized and that appropriate integrity rules are defined to maintain accurate and consistent data.
